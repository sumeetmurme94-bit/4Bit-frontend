# 4BIT VoiceCare - Patient Voice Terminal (Problem Board)

An AI-powered, multilingual voice-enabled patient grievance kiosk and problem reporting terminal, built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features
- **Multilingual Voice Grievance Reporting**: Voice-assisted complaint logging with simulated live speech recognition and audio playback.
- **Kiosk Mode Patient Interface**: Optimized touchscreen interface designed for hospital lobby kiosks and patient check-in counters.
- **Urgent & Emergency Detection**: Real-time triage flags for critical hospital incidents and emergency conditions.
- **Instant Reference Tracking**: Immediate reference ID generation, print receipt simulation, and status updates.

## Tech Stack
- **Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
