# 4BIT VoiceCare - Public Grievance Transparency Portal

A modern, responsive public transparency board for hospital patient feedback and grievance resolution, built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features
- **Public Grievance Transparency**: Real-time read-only civic accountability board for hospital grievances and resolution status.
- **Strict Privacy Guardrails**: Displays aggregated and anonymized feedback while protecting patient identity.
- **Resolution Tracking**: Live progress indicators, department breakdown, and resolution timelines.
- **Patient Reassurance & Reviews**: Community sentiment and patient satisfaction feedback loops.

## Tech Stack
- **Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
